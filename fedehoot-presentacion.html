El producto

¿Qué es Fedehoot?

Fedehoot es una aplicación web de quizzes en tiempo real. Un host crea un quiz con preguntas de opción múltiple o de ordenamiento, genera una sala con un código único, y los jugadores se unen desde cualquier dispositivo usando ese código y un nickname. La partida transcurre en sincronía: todos ven la misma pregunta al mismo tiempo, responden en segundos, y el leaderboard se actualiza en vivo después de cada ronda.

Los proveedores

Claude · Anthropic
Vibe-coding · IA
El asistente de IA con el que se escribió el 100% del código. El desarrollador describe en lenguaje natural; Claude genera, refactoriza y resuelve bugs.
GitHub
Control de versiones
Repositorio del proyecto y fuente de verdad del código. Cada push a main dispara deploys automáticos en Vercel y Railway.
Vercel
Frontend · CDN global · auto-deploy
Sirve la app React construida con Vite. Cada push a GitHub dispara un deploy automático. Free tier con CDN global y HTTPS incluidos.
Railway
Backend · WebSockets · auto-deploy
Corre el servidor Node.js con Socket.IO. Las WebSockets requieren un proceso persistente — por eso el backend vive aquí y no en Vercel.
Supabase
Base de datos · Auth
PostgreSQL hosteado con API REST auto-generada. Gestiona el login con Google OAuth y almacena quizzes, preguntas y respuestas.
Google
Auth · OAuth 2.0
Proveedor de identidad para el login del host. Supabase maneja el flujo OAuth — el usuario inicia sesión con su cuenta Google sin que la app toque las credenciales.
¿Qué es un WebSocket?

HTTP funciona con el modelo pregunta-respuesta: el cliente pide y el servidor responde. Con WebSocket se abre un canal bidireccional y persistente entre el cliente y el servidor — lo que permite que el servidor envíe datos al cliente en cualquier momento, sin que éste tenga que preguntar. Así todos los jugadores reciben la misma pregunta en el instante exacto y el puntaje se actualiza en vivo sin polling.
